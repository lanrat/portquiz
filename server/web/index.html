Results

    A browser can only test ports with web requests, so this is a quick check. It cannot test the ports browsers refuse to use, such as 22 (SSH), 25 (SMTP) and 53 (DNS), or UDP, and it tells closed ports apart less precisely. For a full test, use the command line client or the Android app.
