Results

    A browser can only test ports with web requests, so this is a quick check. It cannot test the TCP ports browsers refuse to use, such as 22 (SSH), 25 (SMTP) and 53 (DNS), it tests UDP more slowly, and it tells closed ports apart less precisely. For a full test, use the command line client or the Android app.
