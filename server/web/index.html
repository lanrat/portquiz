portquiz

GitHub

Tests which ports this network lets your browser reach on this server.

For a complete test, use the command line or Android client from the releases page. They aren't limited by the browser, so they're faster, especially for UDP, test every port, including ones browsers block such as 22 (SSH) and 25 (SMTP), and tell more precisely how each closed port was blocked.

Advanced

This tab is in the background. Browsers slow down background tabs, so the test runs slower until you return to it.

Past runs

This browser keeps your last 20 runs. Check two to compare them. You can also import reports saved by any portquiz client, such as the command line client's -json.

    Results

      A browser can only test ports with web requests, so this is a quick check. It cannot test the TCP ports browsers refuse to use, such as 22 (SSH), 25 (SMTP) and 53 (DNS), it tests UDP more slowly, and it tells closed ports apart less precisely.
